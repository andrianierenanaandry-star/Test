📦 INVENTAIRE DES APPAREILS

🔍 OUTILS DE DIAGNOSTIC (Terminal)

Tapez ces commandes dans votre terminal pour voir qui est connecté :

# Scanner les appareils sur le réseau :
nmap -sn 192.168.1.0/24
# Voir les ports ouverts sur une IP :
nmap -T4 -A 192.168.1.50
# Lister les connexions actives :
arp -a
